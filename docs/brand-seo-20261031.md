# ブランド名検索のSEO整備（2026-10-31）

## 結論と作業範囲

正式名称 **Nail Fit Studio** と「無料・写真/カメラ・アプリ不要」の関係を、ホームの可視テキストと既存の構造化データで明確にした。既存の日本語タイトル、description、H1、画面レイアウト、OG画像を維持。カメラ・スマホ手認識・MediaPipe・試着/追尾・描画・保存ロジックは変更していない。

開始時は `codex/nail-fit-studio-2`、HEAD `32fa7586320e3b3bd4486b7dbd902c40d898aa61`。読み取り専用fetchで同リモートブランチも同じコミットと確認。ユーザーから現在のスマホ認識は正常と報告されている。今回こちらでiPhone/Android実機を再検証したわけではない。

**Gitコミットのみ。push、Vercel公開、Search Console操作、SNSの編集はしていない。** 修正後HTMLの検証対象はローカルの本番build。本番サイトの監査は変更前の公開内容に対する読み取りだけである。

## 2. 変更内容

### ホームの可視テキスト

補助見出し：`無料ネイル試着` → `Nail Fit Studio｜無料ネイル試着`。

リードの冒頭：

- 前：自分の手の写真やカメラで、ネイルの色・形・長さを無料でお試し。
- 後：Nail Fit Studioは、自分の手の写真やカメラで、ネイルの色・形・長さを無料で試せるサイトです。

アプリ不要の説明と試着・診断ボタンは維持した。キーワードの列挙や非表示テキストは追加していない。

**検索タイトルは変更しない：**

無料ネイル試着｜写真・カメラで似合うネイルをお試し - Nail Fit Studio

**Meta descriptionも変更しない：**

ネイルをする前に、自分の手で似合うデザインをチェック。Nail Fit Studioは、写真やカメラでネイルの色・形・長さを無料で試せるサイトです。アプリのインストール不要で、スマホから気軽にお試しできます。

**H1も変更しない：** 自分の手で、似合うネイルを試そう。

ブランド名はヘッダー、直前の補助見出し、直後の説明文で示し、H1の改行・大きさ・スマホレイアウトを保った。

### 既存JSON-LDの整理

既存のWebSite/Organizationグラフを `buildWebsiteJsonLd()` へ集約。ホームで出力するJSON-LDスクリプトは引き続き1個。

- `name`: `Nail Fit Studio`
- `url`: `https://nail-fit-studio.vercel.app/`
- WebSiteの `@id`: `https://nail-fit-studio.vercel.app/#website`
- Organizationの `@id`: `https://nail-fit-studio.vercel.app/#organization`
- `publisher` は上記Organizationを参照。
- descriptionは既存の `SITE_DESCRIPTION` と一致。
- JSON文字列内の `<` をエスケープ。

`nail fit studio` は大文字小文字の違い、`nail-fit-studio` はURLの表記であり、別ブランド名の利用実態は未確認のため `alternateName` を追加していない。未確認のSNSを `sameAs` に登録せず、架空の評価・利用者数・SearchActionも追加していない。

Googleはホームの構造化データと実際のテキスト等を参考にサイト名を生成するが、指定どおりの採用を保証しない。サイト名とページのタイトルリンクは別の要素である。[Google公式：サイト名](https://developers.google.com/search/docs/appearance/site-names?hl=ja)

### ブランドの内部リンク

フッターの既存ブランド文字をホームへのリンクに変更。記事末尾などから正式名でホームへ戻れる。ヘッダーと合わせ、ホームへのブランド名リンクは1個→2個。トップ→試着/診断/ガイド、ガイド一覧→全30記事、各記事→試着/診断は既に正常で、無理に変更していない。

共通SEO更新日は実際の修正日 `2026-10-31` に更新。変更していないガイド本文の編集日は書き換えていない。

## 3. Search Consoleでユーザーが行う作業

以下は所有者アカウントで行う。既に設定済みなら作り直さない。今回の修正を検索に反映させるための再検査は、後日ユーザーが公開した後に行う。現行本番の登録状態は今でも確認できる。

1. [Google Search Console](https://search.google.com/search-console) を開き、プロパティ `https://nail-fit-studio.vercel.app/` を選ぶ。なければ「プロパティを追加」→「URLプレフィックス」にこのURLを入れる。Vercel共用ドメインのDNSを所有しているとは仮定しない。
2. 必要なら所有権を確認する。Googleが表示するHTMLタグ方式など、実際に提示された方法を使う。AdSense承認とSearch Console所有権確認を同じものとして扱わない。確認用トークンは未提供なので、今回は推測したタグを設置していない。
3. 上部「URL検査」に `https://nail-fit-studio.vercel.app/` を貼る。「Googleに登録されているか」「最終クロール」「Googleが選択した正規URL」を確認する。正規URLの判定はインデックス済みデータ側で確認し、ライブテストだけで確定しない。
4. 「公開URLをテスト」で取得・レンダリングを確認。取得失敗、noindex、サーバーエラーなどがあれば、表示される具体的な理由を先に解消する。更新公開後、登録可能なら「インデックス登録をリクエスト」。同じURLを繰り返し送っても即時掲載の保証にはならない。[Google公式：URL検査](https://support.google.com/webmasters/answer/9012289?hl=ja)
5. 左メニュー「サイトマップ」で、新しいサイトマップに `sitemap.xml` を入力し、最終URLが `https://nail-fit-studio.vercel.app/sitemap.xml` であることを確認して送信。既に「成功」なら重複登録は不要。取得できない場合は該当行を開き、エラー・最終読み込みを確認する。送信は場所を知らせる操作で、全URLの登録を保証しない。[Google公式：サイトマップ](https://support.google.com/webmasters/answer/7451001?hl=ja)
6. 「ページのインデックス登録」で、失敗URL・除外理由を確認。重要な `/try-on`、`/diagnosis`、`/guide` と代表記事もURL検査する。お気に入り・履歴の意図的なnoindexや、存在しないURLの404を、無条件に解除しない。
7. 「検索パフォーマンス」→検索結果で、ブランド語 `Nail Fit Studio` / `nail fit studio` / `nail-fit-studio` のクエリ、ページ、国、デバイスを確認。表示回数・クリック・CTR・平均掲載順位を、同じ期間条件で記録する。大文字小文字が集約される場合は別々のデータがあると仮定しない。平均掲載順位は、今この瞬間の全ユーザーに共通する順位ではない。[Google公式：検索パフォーマンス](https://support.google.com/webmasters/answer/7576553?hl=ja)

Search Consoleの非公開データを未確認のまま「未登録」「1位達成」「Googleが公式と認定済み」とは報告しない。

## 4. SNS・ポートフォリオの手動作業

ユーザーが管理している実在のSNSプロフィール、ポートフォリオ、開発紹介記事でのみ実施する。

- 名前/紹介文を `Nail Fit Studio` にそろえる。
- リンク欄には公式ホーム `https://nail-fit-studio.vercel.app/` を設定。
- 例文：**Nail Fit Studioは、自分の手の写真やカメラで、ネイルの色・形・長さを無料で試せるサイトです。アプリ不要。**
- 関連する紹介記事には、読者に役立つ自然な文脈で公式ホームまたは該当ガイドへリンクする。無関係なサイトへの大量投稿・リンク購入・自動投稿は行わない。

今回、プロフィール所有者の確認・アカウント作成・外部投稿は行っていない。所有を確認した公開プロフィールが揃った段階でのみ、必要なら `sameAs` の追加を別途判断する。

Yahoo!についても、改修が即時反映されることやGoogleと同じ順位になることは保証しない。公開後、3種類のブランド検索をそれぞれGoogle/Yahoo!で確認し、日時・端末・実際の表示を記録する。[Yahoo!公式：インデックスの更新について](https://support.yahoo-net.jp/PccSearch/s/article/H000007972)
