### 座標と描画

`PaintView` は倍率と爪幅単位の表示中心だけを持つ。半画面の余白を含む有限のスクロール範囲で、爪の両端へ到達できる。ピンチの指間中心を爪座標へ逆変換し、その点を保ちながら倍率とパンを同時更新する。指を切り替えても、その編集セッション内の表示位置を維持する。再読み込み時は安全な全体表示から始め、作品JSONへ表示倍率・スクロール位置を保存しない。

パンはスクロールのみ。ピンチ中はCSS表示寸法だけをrAFで更新し、終了時にCanvasの解像度を再生成する。毎moveでベクターを再ラスタライズしない。背面CanvasはDPR上限2、既存の約400万画素制限を維持。ドラッグ配置の領域判定もCanvas直近の親ではなく `.paint-viewport` を使用する。

## 3. 新しい操作方法

1. `/create` または試着中のエディターで指を選び「拡大して絵を描く」。最初は爪全体が見える。
2. **描く**：1本指/マウスで描画。ブラシ・ドット・消しゴム等は「ブラシ・図形・レイヤーの設定」から選ぶ。
3. **移動**：1本指/マウスで表示だけを上下左右へ移動。**どのモードでも2本指でパン＋ピンチ**できる。ピンチ後に残った指では描かず、すべて離してから描画を再開する。
4. **選択 / 図形 / 素材**：操作目的を分離。素材一覧は必要時だけ開く。38種、検索、分類、タップ配置、ドラッグ配置、数値微調整を維持。
5. **− / ＋ / 100%表示 / 全体表示** で戻せる。全体表示は長さ変更・画面サイズにも対応。
6. **画面を広く使う**：同じCanvasのままヘッダー/下部ナビを覆う集中編集へ。Safe AreaとVisualViewportを利用。通常表示へ戻るボタン、Escape、Tab移動・背景inert・フォーカス復帰に対応。新しい開閉アニメーションはない。既存の動きを減らすCSSを維持。
7. Canvasの近くにUndo/Redo、保存、試着、5本一覧へのボタンを置く。詳細と素材一覧は別々の折りたたみ/スクロール領域に整理。

### 未保存データの安全性

- 正式なコレクション保存とは別に、確定済みの編集を約900msの操作休止後、同じブラウザへ一時退避する。描画途中のプレビューは保存しない。
- ページ非表示・離脱・SPA移動時も確定済み内容の退避を試す。退避にも失敗した場合のみbeforeunloadの確認を要求する（OSによる突然の強制終了を防げる保証ではない）。
- 最大5作品、合計700,000文字。既存作品を自動追い出ししない。未知スキーマ・壊れたJSON・容量不足を上書きせずエラーを示す。
- 再訪時は利用者が「復元」を選ぶ。正式保存は押すまで実行せず、保存成功時に同じ作品の退避だけを整理する。明示的な破棄には確認する。
- 写真/映像やCanvas画像は退避しない。端末内データ削除の既存名前空間に含める。プライバシー説明へ一時退避を追記。
