## 操作方法

1. `/create` の5本一覧で指を選び、「拡大して絵を描く」または各指の「拡大編集」を押す。
2. ペン/ブラシ/ドット/消しゴム/ラメ/ホログラム、または図形を選ぶ。色・太さ・不透明度・間隔を設定して爪の内側からドラッグする。
3. 正円・正方形はドラッグ方向によらず縦横比を固定。図形はドラッグ中も表示される。
4. 「選択・移動」またはレイヤー一覧で対象を選び、位置・回転・大きさ・幅/高さ・曲線の曲がりを変更する。複製/削除/前後移動も可能。
5. 拡大/縮小ボタン（1〜2.5倍）と「表示を移動」で画面を動かす。「描くキャンバスへ戻る」で設定から戻る。
6. 必要に応じて別の指/5本へコピーし、「デザインを保存」。コレクションから再編集できる。
7. 「このデザインで試着」で写真またはカメラへ。ライブ中は「5本のデザインを編集」から同じストリームのまま描ける。

自動保存ではない。保存はこの端末・ブラウザのみ。写真/カメラ画像をデザインデータとして送信・永続保存しない。
消しゴムは下の手描き・図形だけに作用し、ベースや13種類の装飾を消さない。
フレンチ曲線は保存されるオブジェクト、破線のフレンチガイドは編集補助であり保存/試着には出ない。

## データ・座標・互換性

- 旧document schema=1は読み込み可能。読み込みだけで書き換えない。
- 手描きを初めて変更するとdocument schema=2へ。5本それぞれに `layers` と装飾を含む `order` を持つ。
- ストロークはポイント列、図形は種類・寸法・スタイル・変形を保存する。ビットマップへの確定ではない。
- 中心は爪幅/爪長の比。ポイント列・図形寸法・線幅は両軸とも爪幅単位（等方）。正円をDPRや縦横比の丸めで楕円にしない。
- 表示倍率/スクロール/DPRとモデル座標を分離。カメラでは既存の爪幅・長さ・回転・表示領域変換をそのまま継承。
- 既存の爪形状、部分可視性輪郭と穴のクリップ内に描画する。爪が非表示の指は手描きも非表示。
- コピーはポイント列を深く複製し、全レイヤーIDと重ね順を対応させる。他の指の編集で変化しない。
- 旧アプリはschema=2を認識できず拒否する。旧版へ戻すと手描きデータを編集できないが、勝手に切り捨てて上書きしない。
- 保存キーとライブラリ外側schemaは従来どおり。未知/破損データ、容量超過時は保存成功を表示しない。

## 入力・描画・安全策

Pointer Eventsでマウスとタッチを統一。pointer capture/coalesced eventsと最終pointerupを取り込み、丸端の滑らかな曲線を描く。
入力途中のプレビューはrAF単位。1ドラッグ=1 Undo。キャンセル/キャプチャ喪失時は元のデータとRedoを復元する。
`touch-action: none` は描画Canvasに限定し、設定やページの通常スクロールは維持する。

編集用CanvasはDPR最大2、最大400万画素。大きさが変わらないフレームではbackingを再確保しない。
保存画像は小さなプレビューを拡大せず、既存の写真前処理後の画像サイズまたは動画の実解像度に対してベクターを再描画する。
既存の巨大画像縮小制限は維持するため、撮影元の無制限な原寸保証ではない。

1指につき手描き32レイヤー/合計4096点/1ストローク256点/消しゴム8本、装飾12個。
点列は上限に達したら端点を残して間引く。ドット/ラメは軌跡全体を覆いつつスタンプ数を制限する。
Path2Dを不変ポイント配列でWeakMapキャッシュ。完成合成は最大6面かつ計400万画素、サイズ更新時は古い面を解放する。
消しゴムの後続マスクを共有し、同じパスの繰り返し描画を削減。補助マスクは計200万画素を上限とし、巨大出力はパス方式へ戻す。

手描き用Canvas生成に失敗した場合、試着プレビューはベース/装飾を継続し、案内を表示する。
カメラや認識を停止する処理は追加しない。一方、画像保存では手描きが欠落したまま成功にしない（従来の保存エラーへ）。

## 残る制約・実機チェック

ピンチズームではなく専用ボタン+表示移動を採用。筆圧/パス制御点の直接編集は未実装。線はオブジェクト全体の変形、曲線は曲がりの編集。
消しゴムは写真/ベースを消さず、下の各手描きオブジェクトを削る方式。大量レイヤーでは上記の負荷が残る。
手描きは爪局所2Dベクターであり、物理的な3D顔料/曲面射影を完全再現するものではない。

公開判断の前に、iPhone Safari/Android Chrome実機で次を実施する：

1. `/create` で指描画・細線/太線・消しゴム・図形・ズーム/移動・Undo/Redoを操作する。
2. 通常のページスクロールと描画を行き来し、縦横回転、タッチキャンセル、短い画面、複数タッチを確認する。
3. 保存→再読込→コレクション再編集→写真試着→Before/After→保存/共有を確認する。
4. カメラで甲5本、距離変化、曲げた指の部分表示、掌非表示、認識復帰、親指位置を確認する。
5. ライブ編集後もstream/模様が残り、カメラ停止/離脱で解放されることを確認する。
6. 普通の構成と最大構成を分け、発熱・電池・長時間メモリ・実FPS・保存画像の画素品質を確認する。
