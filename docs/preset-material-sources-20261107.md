## 改変・配布

- EXIF方向補正、爪1本の手動ポリゴン切り抜き、境界内側の除去、爪先が上になる回転、連続走査線による表面展開、PNG変換。写真にないディテールの生成やランダム断片の合成はしない。見本は余白を付けて縮小。ホームの参考写真は960px以内へ縮小した全景を別経路で維持。
- CC BY-SA素材の加工画像は元と同じライセンスを記録。CC BY、CC0も個別に記録し、出典を不明な一括ライセンスに置き換えない。作者、元画像URL、ライセンスURL、変更内容はpublic/assets/preset-materials-v2.jsonと静的PNGメタデータに含む。
- 保存する試着PNGにも使用した素材の出典をiTXtとして埋め込む。画像寸法や画素は変えない。SNS等でメタデータが除かれる場合があるため、公開・再配布時は画面の出典リンクを使ってクレジットを別途添える必要がある。
- キャラクター写真046は写真のCC表示だけで別途キャラクターの権利まで確認できないため採用せず、一般的な花柄へ再選定。020はCommons由来として確認できず採用しない。
- 原寸029のWebPは明示的に形式を記録して一度検証したが、拡大品質が不足したため最終版には採用していない。PNGへ変換しただけで高精細化したとは扱わない。

## 再現方法

Python/Pillow/numpyはオフライン素材作成だけに使用し、本番依存へ追加していない。原寸は公開JSONのoriginalUrlから取得しSHA256/公式SHA1を確認する。作業用原寸・確認前候補はGitへ含めない。

```powershell
python scripts/build-preset-surfaces.py --metadata docs/preset-verified-sources-v2.json --source-dir <検証済み原寸フォルダー> --out <公開外の候補出力先>
```

候補の全件目視後だけ、`--out public/assets --publish-reviewed`で配布素材と型付きURL表・既存プリセットJSONを更新する。元ファイルのSHAが変わる場合は処理を中断する。画像の内容ハッシュをURLに含め、Next/imageの古い最適化キャッシュを再利用しない。
