## 2. 現行パイプラインと不足していた点

利用者の操作は `/create` で材質・手描き・装飾を選択 → 爪ごとの正規化データ → `/try-on` の写真またはローカルカメラ → MediaPipe姿勢・既存の可視性/輪郭 → 同じCanvasレンダラー → 保存/再編集、という流れ。新しいサーバー通信は不要。

1. 外側のcontain領域へ座標を変換し、各指の可視性と画像由来の部分輪郭（穴を含む）をclip。
2. `nailCanvasGeometry` の根元・中心・幅・高さと回転で爪ローカル座標へ変換。既存 `buildNailPath` でもclipする。
3. 根元影 → 色またはジェル色 → 写真素材/模様/質感 → 手描き・装飾（保存された順番、個別alpha、消しゴム）→ ジェルのトップコート。
4. 実写プリセットは写真中の反射をそのまま使う専用分岐。新しい擬似ハイライトを重ねない。通常のRGB色表面とは分離。
5. 手描き/装飾は既存の最大4,000,000画素のキャッシュ、同一prefix再利用、Path2D再利用、pagehide時の解放を継続。現在の可視性maskと姿勢はキャッシュ外で毎回適用。

コードと比較画像で確認した不足：旧標準材質は幅広い白かぶりと一様な白線、装飾は球・平面箔・透明ジェルにも同じ濃い楕円影/白い点を使っていた。ラメの丸粒とマグネットの白線も合成感の要因。一方、輪郭/位置の誤差そのものは光沢変更で直らないため、今回それを隠す加工は行っていない。

写真とVIDEOは同じ描画関数を共有。VIDEOの既存スケジューラ・推論頻度・古いフレーム抑制・One Euro Filter・鏡像処理は変更なし。照明は従来の24×24画素、最大4Hz、brightness/warmthの低域通過推定をそのまま使用。光源方向・環境マップ・世界座標法線を画像から復元したものではない。

## 3. 採用した描画変更

### 爪・ジェル・特殊材質

- 標準材質：横方向の白かぶりと幅広い反射を弱め、細い反射は縦方向に透明度が変わるものへ変更。小爪にも固定最小0.5pxの白線を強制しない。
- ジェル：根元へ向かう色alphaを急に抜かず、短い中間stopを追加。色の選択値は変えない。シアーは元画像を消さない既存のsource-over合成を維持。マットは従来の色stopを維持。
- トップコート：向きに応じた既存の反射位置計算はそのまま、細い反射の幅/強度を調整。爪先に厚み依存の微弱な曲線を**mask内**へ追加。マットには追加しない。
- グラデーション：単純な縦の直線状の色落ちから、爪幅/爪長で正規化した先端側の楕円状の広がりへ変更。
- マグネット/キャッツアイ：筋の中心だけを強い白にせず、肩・周囲・中心の弱い階調と、筋からの距離による粒の輝度を組み合わせる。視線依存BRDFではなく2D近似。
- ラメ/ホロ：固定シードから粒ごとの大きさ・縦横比・角度・alphaを決める四角い薄片。毎フレームの乱数やタイマーは使わない。オーロラの虹色は弱める。
- フレンチの境界形状、旧マーブル/天然石風の線、旧surfaceEffectは変更していない。共通コートの変化だけを専用の境界精度改善とは呼ばない。

### 13種類の装飾

材質別の補助関数を `partRendering.ts` へ分離。爪内の座標・p.size・p.rotation・レイヤー順・alpha・クリッピングの契約は維持。

- ストーン/クリスタル：明暗の違う面、内部の小さな輪郭、エッジ、小さなハイライト。小さい半径や既存の軽量モードでは面数を抑制。実屈折はしていない。
- パール：暖色寄りの柔らかい広い反射、下側の陰影、薄い干渉色風の縁。金属のような硬い白点を弱めた。
- リボン：左右の曲面ループ、折り目、中央の結び目。3Dメッシュではない。
- ハート/ジェル：側面のalphaと短い反射、材質に応じた細い接地影。背後の画素を曲げる屈折や物理的な光透過は未実装。
- 金/銀箔・星：球状の同一グラデーションから、薄片の面と小さいエッジへ。ラメ装飾も丸粒を不規則な薄片へ。
- 接地影：材質に応じた狭い中心と薄い周辺を使用。汚れのような大きい黒楕円を一律に付けない。
- **花/シェルは既存の材質描画を保持**。新案で花弁の奥行きと貝の筋が弱くなったため、採用しなかった。

全てCanvas2Dの解析的な擬似材質。新たなCanvas backing surface、GPU shader、blur、画像readback、毎フレームの乱数をアプリに追加していない。親爪の変換へ追従するが、独立した装飾3D姿勢や接触形状を推定したわけではない。
